# Html-Components-

A collection of HTML/CSS/Bootstrap practice pages (assignments + component examples) created while learning web development.

## What’s inside

- Plain HTML examples (forms, tables, lists, layout, etc.)
- Bootstrap component demos (navbar, cards, modal, carousel, tooltips, grid, validation, etc.)
- A couple of shared stylesheets: `style.css` and `style2.css`

## How to run / view

No build step is required.

1. Open any `.html` file in your browser (double-click it), or
2. Use VS Code “Live Server” (recommended) and open the page from the local server.

## Suggested starting pages

- `bootstrap_example.html` / `bootstrap_grid.html` (Bootstrap basics)
- `form.html` / `validationbts.html` (form elements + validation)
- `navbarlogobts.html` / `cardsbts.html` / `modalbts.html` (common UI components)

## Folder notes

- `sample/` contains media files used by some demo pages.
